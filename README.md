**AI-powered surveillance with cryptographic evidence integrity.**

A security-first platform designed to transform surveillance detections into traceable, protected and auditable digital evidence.

- AI-powered object detection and RTSP streaming.
- Evidence encryption and digital signatures.
- Cryptographic integrity verification.
- Role-based access control and audit logging.
- Digital chain-of-custody workflows.

**Stack:** Python · FastAPI · OpenCV · PostgreSQL · Redis · Docker

### ⚙️ 3. DevPulse — Internal Developer Portal

**Developer productivity and security automation.**

An internal engineering platform that consumes GitHub webhooks, tracks pull-request activity and enforces security policies.

- Secure webhook ingestion using HMAC-SHA256.
- Idempotent event processing.
- Pull-request velocity analytics.
- Automated security gates.
- PostgreSQL-backed metrics.

**Stack:** TypeScript · Node.js · Express · Next.js · Prisma · PostgreSQL

[![Repository](https://img.shields.io/badge/Explore_Repository-181717?style=for-the-badge&logo=github)](https://github.com/lesley-cyborg/devpulse-internal-developer-portal)
